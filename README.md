# MarketIQ
# Financial Dashboard - Real-Time Stock, Mutual Fund, and Crypto Tracker

A comprehensive, real-time financial dashboard built with **Spring Boot**, **HTML/CSS/JavaScript**, and **Chart.js**.  
It displays live prices for stocks, mutual funds, and cryptocurrencies with real-time updates via **WebSocket**.

---

## Features
- Real-time price updates every 10 seconds.
- Search financial instruments by symbol or name.
- Responsive dashboard UI.
- Interactive charts (1-minute, 5-minute, daily intervals).
- User authentication for personalized watchlists.
- API rate limiting and caching for efficient data fetching.
- Dockerized setup for easy deployment.

---

## Tech Stack

| Layer | Technology |
|:------|:-----------|
| Backend | Java 17, Spring Boot, WebSocket, JPA |
| Frontend | HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+), Chart.js |
| Database | PostgreSQL |
| APIs Integrated | Finnhub (Stocks), Morningstar (Mutual Funds), CoinGecko (Crypto) |
| DevOps | Docker, Docker Compose |
